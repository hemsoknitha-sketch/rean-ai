## 4. SUPER SMART COPIEDABLE CODE BLOCK ENGINEERING

In modern messaging interfaces, friction in copying code diminishes learning velocity. The system enforces zero-friction copyability:

### A. Syntax Specification
- All multiline code blocks must be output as:
  ```html
  <pre><code class="language-python">
  # 100% complete, runnable code
  import ...
  </code></pre>
  ```
- All prompt templates must be output as:
  ```html
  <pre><code class="language-yaml">
  role: system
  ...
  </code></pre>
  ```
- All inline commands or tokens must be output as:
  ```html
  <code>pip install google-genai</code>
  ```

### B. Client-Side Telegram Behavior
- On Telegram Desktop & Mobile, `<pre><code class="language-...">` renders a native **"Copy Code"** button in the header of the block.
- On Mobile, tapping `<code>` copies the inline command directly to the clipboard.
- **The Zero-Placeholder Rule**: Code must NEVER contain `# TODO`, `# Add your code here`, or ellipses `...`. Every script must be 100% complete, syntactically valid, and ready to execute immediately.
